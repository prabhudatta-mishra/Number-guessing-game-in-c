# Number Guessing Game
This is a simple number guessing game made in C.
The computer generates a random number between 1 to 100.
User tries to guess the correct number.
## Features
- Random number generation
- User input
- High / Low hints
- Simple C program
## How to Run

1. Compile the program
gcc game.c -o game

2. Run the program
./game
gcc game.c -o game.exe
game.exe
## Example Output

Enter your guess: 50
Too Low!

Enter your guess: 75
Too High!

Enter your guess: 63
Correct Number!
